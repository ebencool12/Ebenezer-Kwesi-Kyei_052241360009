How to set up the cloud database (one time)
  1. Create a free project at supabase.com.
  2. Open SQL Editor, paste the SQL below and press Run.
  3. Open Project Settings → API, copy the Project URL and the anon public key into the boxes above.
  4. Enter the same URL and key on every phone or computer that should share the stock.
create table if not exists public.stock_docs (
  id text primary key,
  data jsonb not null,
  updated_at timestamptz not null default now()
);

create or replace function public.stock_docs_touch()
returns trigger language plpgsql as $$
begin
  new.updated_at = now();
  return new;
end; $$;

drop trigger if exists stock_docs_touch on public.stock_docs;
create trigger stock_docs_touch
  before insert or update on public.stock_docs
  for each row execute function public.stock_docs_touch();

create index if not exists stock_docs_updated_idx
  on public.stock_docs (updated_at);

alter table public.stock_docs enable row level security;

drop policy if exists "shop devices" on public.stock_docs;
create policy "shop devices" on public.stock_docs
  for all using (true) with check (true);

Keep the key private to the shop. Anyone who has both the URL and the key can read and change the stock.
